This project is a Word Scramble Game developed using the C programming language.
The program randomly selects a word, scrambles its letters, and asks the user to guess the original word.

The user plays for a fixed number of rounds. For each correct answer, the score is increased.
At the end of the game, the final score is displayed and the user is given an option to play again.

The project uses basic C programming concepts such as arrays, strings, functions, loops, conditional statements, and random number generation.
